# 报告bug

## 需要提问者说明：
- 你之前想干啥？ (为什么？)
- 发生了啥？
- 预期想得到啥结果?
- 复现你遇到bug的操作步骤.
- 为了解决bug，你已经做了哪些尝试？

## 需要提问者提供以下信息
- 操作系统类型？
- 应用版本？
  - 不同开发语言的程序提供RE/DK版本号，i.e. java程序提供JRE或者JDK版本号;




# 最需要注意的要点

- **无论何时，在求助他人之前，自己先通过搜索引擎尝试独立解决问题。**
  - [Google](https://www.google.com)
  - [Baidu](https://www.baidu.com)
  - [Stack Overflow](https://stackoverflow.com)
  - [GitHub](https://github.com)
 
- 遵守小朋友们的基本礼仪。
```text
请问
  ...问题描述...
谢谢
```

# 例子
## 正例
- 请问
- 一个关于 `什么` 的问题。
- 我想要达到 `什么样` 效果，但是我这样做出现了 `什么样` 的问题。
- 报错日志是 `这样` 的。（画关键字）
- 我尝试过 `什么` 方法来解决。
- 我尝试搜索过了 `什么` 关键字，在里面找到了 这些 `URL` 的回答，尝试了还是没有解决问题。
- 我用的是 `什么` 操作系统，版本号是多少。
- 我用的是 `什么` 软件，版本号是多少。
- 谢谢

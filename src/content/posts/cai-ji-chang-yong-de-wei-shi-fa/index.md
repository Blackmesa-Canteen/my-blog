# 偷懒肉食

1. 卤肉: 关于卤制的具体细节会记叙在另一个文档里, 待更新;
2. 封装: 一次卤制大量食材, 分割并封装进分布式容器, 每顿拿出来一个容器使用之;
3. 烹饪食材: 一般地, 准备姜葱蒜(可选小红辣椒), **清洗之**, 有些食材(比如肥肠)可以额外准备青椒4~5和洋葱2, 青椒去头, 洋葱别忘去皮, **清洗之**. 洋葱简单切几块就好, 炒制时会自动离散. (为健康膳食, 可以搭配绿叶子菜等).

首先, 开!抽!油!烟!机! 然后入油进锅, 加热些许, 入姜葱蒜(小红辣椒)炒制. 

少顷, 味微香, 方可卤肉入锅, 翻炒之. 少间, 料酒入. 

俄而青椒入, 待青椒熟后, 洋葱入. 少焉, 试入实验, 品尝之, 微调其量. 味OK则出国可.

# 不是很偷懒的偷懒肉食
1. 肉类腌制: 肉洗净切丁，放入白酒(料酒也可)、姜丝、生抽、花椒, 少许砂糖, 蒜末(拍碎了切), 可加淀粉少量, 拌匀，盖上保鲜膜;
2. 素菜搭配: 青椒, 木耳, 蒜薹,白菜... 太多了, 请上网自查之;
3. 烹制: 仿照上述偷懒肉食烹饪食材, 可能需要额外用到生抽,老抽以及豆瓣酱. 注意下先肉后素.

# 鱼

**首先, 不建议开锅烧热油炸/煎鱼, 作为菜鸡, 油会炸得到处都是, 鱼还碎了.**

1. 调料: 姜,葱,蒜, 豆瓣酱
2. 调料入锅, 用油炒制. 加水(100mL?), 入鱼, 倒酱油, 一点点醋, 一点点糖, 料酒. 盖锅盖15分钟左右. 出锅前, 继续烧, 把多余的水烧掉, 留点汤汁. **注意泡沫会让人以为是还有很多水, 从而导致过干.**

# 虾
网上找的一个方法, 待尝试
1. 洗, 除虾线.
2. 我们要先将虾外壳清洗干净，把外壳给去掉，姜蒜要切成丝，虾肉用冰水洗干净然后沥干水分，然后放入蛋清食用盐, 味精or少许糖, 搅拌均匀，紧接着放入切成丝的姜蒜，再放上一些淀粉上浆，还可以放入一点料酒，然后用丝网皮将虾包起来放入油锅炸，炸熟之后就可以吃了，这种做法非常好吃哦。


# 煮萝卜配蘸料
1. 加水, 烧;
2. 萝卜, 去皮, 清洗, 切成厚片;
3. 入锅, 开后小火, 整个半小时;
4. 蘸料: 油泼辣子, 酱油, 少量糖, 可少量醋.

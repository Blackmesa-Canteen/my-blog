The tools we will be using in this workshop are the GNAT Ada compiler and GNAT Programming Studio (GPS). These come bundled together as part of GNAT Community Edition. For this subject we will be using GNAT Community Edition 2019. (Newer versions are also available but do not support all platforms equally. Hence for this subject we use the 2019 version to ensure everyone can run the same version of the tools on their machine.)

You should download an install GNAT Community Edition from https://www.adacore.com/download/ more.
